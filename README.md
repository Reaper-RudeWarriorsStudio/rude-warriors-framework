# ⚔️Rude Warriors Framework
**Focused Unity Framework**  
Built by **Rude Warriors Studio**

A clean, modular foundation for Unity projects.  
Simplifies the scene view, automates editor setup, and lets devs focus on creation instead of clutter.

---

## ✴ Features
- **Scene Channel:** replaces the default hierarchy
- **Focus Mode:** isolate active objects
- **Service Locator + Event Bus:** lightweight game backbone
- **External Editor Link:** defaults to VSCode or custom path
- **Modular Prefabs + Bootstrap Samples**

---

## 🧠 Philosophy
> “Fewer clicks. More creation.”

This framework was designed to help developers with attention deficit disorder (ADD/ADHD) stay focused on a single workflow channel.  
No distractions. No unnecessary noise. Just game-building.
